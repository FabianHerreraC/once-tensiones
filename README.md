# 50 años construyendo un bosque

Página local para componer árboles a partir de 22 geometrías 3D: once tensiones, cada una entre dos polos.

- **Taller:** catálogo de tensiones (clic para leer cada concepto), deslizadores entre polos, raíz reflejada bajo el suelo, exportar PNG.
- **Bosque:** los árboles guardados con nombre se plantan en una cuadrícula, uno por cuadrante, con una franja de sus colores pintada en el suelo. Buscador por nombre.

Es un solo archivo: abre `index.html` en el navegador (necesita internet para cargar three.js). Los árboles guardados viven en el almacenamiento local del navegador.
